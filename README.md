# Study Lab 3.0
Washington P&C personal study app. Enable Settings > Pages > Deploy from a branch > main > / (root). No build required.

The shared questions.json contains 20 assistant-created practice questions. Add new questions with unique stable IDs and the same JSON schema. Reopening the app online merges new questions without deleting local progress; existing IDs are not overwritten. Course questions and personal progress should be imported locally through Backup, not committed to this public repo. Export a full backup to migrate devices. Local progress does not sync across devices.

Offline access is available after a successful online visit and service worker installation. On iOS use Safari > Share > Add to Home Screen; Android use Chrome > Add to Home Screen/Install if available.
